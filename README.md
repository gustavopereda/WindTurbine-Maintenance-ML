# ReneWind – Predictive Maintenance for Wind Turbines 

## Overview
Used time-series sensor data to predict wind turbine generator failures and prevent unplanned downtime.

## Key Metrics
- GBM Accuracy: 99.8%
- Recall: 100% – prioritized to catch all failures

## Tools Used
- Python (Scikit-learn, XGBoost, Pandas)
- Imbalanced classification techniques
- Jupyter Notebook

## Deliverables
- EDA on sensor and failure logs
- Ensemble model development and tuning
- Operational business case

## Recommendation
Deploy model in real-time monitoring systems for wind farms to reduce maintenance costs and increase efficiency.
